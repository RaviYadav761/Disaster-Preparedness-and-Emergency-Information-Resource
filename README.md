🚀 Getting Started

Follow these steps to run the project on your local machine.

1. Clone the Repository
git clone https://github.com/RaviYadav761/Disaster-Preparedness-and-Emergency-Information-Resource.git
2. Open the Project Folder
cd Disaster-Preparedness-and-Emergency-Information-Resource
3. Install Dependencies
npm install
4. Start the Development Server
npm run dev

The application will usually run at:
http://localhost:5173/
