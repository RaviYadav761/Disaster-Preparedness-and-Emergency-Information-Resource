# 🌍 Disaster Preparedness and Emergency Information Resource

A web-based Community Engagement Project designed to provide citizens with accessible information about disaster preparedness, emergency situations, and safety guidelines.

## 📌 About the Project

The **Disaster Preparedness and Emergency Information Resource** is a web-based awareness platform developed as part of a Community Engagement Project.

The purpose of this project is to provide citizens with useful and easy-to-understand information about different types of disasters, emergency preparedness, preventive measures, and safety guidelines.

The website focuses on **awareness, preparedness, and information sharing** to help communities become better prepared for emergency situations.

## 🎯 Objectives

- Create awareness about different types of disasters.
- Provide disaster preparedness information.
- Provide safety guidelines for emergency situations.
- Make important emergency information easily accessible.
- Help users understand basic preventive and safety measures.
- Apply Computer Science concepts to a real-world community requirement.
- Develop a responsive and user-friendly web platform.

## 🚨 Disaster Categories

- ⚡ Lightning

- 🌊 Flood
- 🏭 Chemical & Industrial Disaster
- 🌡️ Heat Wave

- Responsive web design
- Mobile-friendly interface

🚀 Getting Started

Follow these steps to run the project on your local machine.

1. Clone the Repository

git clone https://github.com/RaviYadav761/Disaster-Preparedness-and-Emergency-Information-Resource.git

2. Open the Project Folder

cd Disaster-Preparedness-and-Emergency-Information-Resource

3. Install Dependencies

npm install

4. Start the Development Server

npm run dev

The application will usually run at:

http://localhost:5173/
